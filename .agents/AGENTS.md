# Project Rules & Constraints

## Rule: Planning and Communication Flow
- **Ask Before Acting**: Do NOT modify codebase files or execute commands on the system without first writing out your planned approach, asking the user clarifying questions, and obtaining explicit confirmation.
- **Explain Intent First**: Always output a clear description of the actions you intend to perform, outline the design decisions, and request approval before moving past the planning phase.
- **Do Not Waste Tokens**: Avoid redundant execution, unnecessary file reads, or complex steps that are not aligned with user approval.
