# ПРАВИЛА ТА АРХІТЕКТУРА ПРАЙСУ WEBSKLAD (ДЛЯ МАРКЕТПЛЕЙСУ KASTA)

Цей документ фіксує непорушні правила обробки, ціноутворення, валідації та ізоляції фіду **Websklad**. Будь-який розробник або AI-агент зобов'язаний дотримуватися цих правил, щоб уникнути збоїв на маркетплейсі **KASTA** та блокування безкоштовного тарифу **Cloudflare Worker**.

---

## 1. СУВОРА ІЗОЛЯЦІЯ ВІД ІНШИХ ПРАЙСІВ

Репозиторій містить 3 незалежні системи прайсів. **Websklad має бути 100% автономним:**

1. **Не чіпати інші прайси:**
   * **AGER** (`AGER_process_feed.js`, `.github/workflows/update-ager-feed.yml`, гілка `feeds`).
   * **MASTER_KASTA** (папка `MASTER_KASTA_XML/`, `.github/workflows/masterkasta.yml`, скрипти Python).
2. **Файли Websklad:**
   * Скрипт обробки: `websklad-processor.js` (у корені гілки `main`).
   * Тести та валідатор: `test-websklad.js` (у корені гілки `main`).
   * CI/CD Workflow: `.github/workflows/websklad.yml`.
   * Цільова гілка для готового XML: **`feeds-websklad`** (файл `websklad.xml`).
3. **Обмеження тригерів:**
   * Workflow `websklad.yml` запускається по push **виключно** при зміні файлів `websklad-processor.js`, `test-websklad.js` або `.github/workflows/websklad.yml`.
   * Коміти у `MASTER_KASTA_XML` чи `AGER` не повинні тригерити збірку `websklad`.

## 2. ПРАВИЛА ДЛЯ МАРКЕТПЛЕЙСУ KASTA

### 2.1. Унікальність товарів (Offer ID)
* До кожного ID товару від постачальника Websklad **обов'язково** додається числовий префікс **`1818`** (наприклад: ID `3325` $\rightarrow$ `18183325`).
* Це виключає конфлікти та дублікати SKU з іншими постачальниками на Kasta.

### 2.2. Правила націнки (Tiered Pricing)
* **Мінімальний поріг:** товари з вхідною ціною $< 150$ грн відфільтровуються (`MIN_PRICE = 150`).
* **Товари до 1000 грн ($\le 1000$ грн):**
  $$\text{Ціна продажу} = \text{round}(\text{вхідна ціна} \times 1.45 + 40)$$
* **Товари дорожче 1000 грн ($> 1000$ грн):**
  $$\text{Ціна продажу} = \text{round}(\text{вхідна ціна} \times 1.40 + 50)$$

### 2.3. Захист від помилки `PRICE_ERROR` (Стара ціна)
* Kasta суворо вимагає: якщо вказано `<oldprice>` (закреслена ціна), вона **завжди повинна бути більшою за `<price>`** (`oldprice > price`).
* Якщо $\text{oldprice} \le \text{price}$, Kasta блокує імпорт товару з помилкою `PRICE_ERROR`.
* **Правило розрахунку:** stara ціна також розраховується за формулою націнки, і додатково гарантується мінімум 20% перевищення:
  $$\text{finalOld} = \max(\text{computedOld}, \text{round}(\text{newPrice} \times 1.20))$$

### 2.4. Чистота описів та стоп-слова
* Описи очищаються від CDATA та HTML-розмітки.
* Видаляється рекламний та відео-шум: маркери `🔴`, `👇`, `👉`, згадки про відеорозпаковки, передоплати та конкуруючі сайти.
* Обов'язкова наявність назви (`<name>` або `<name_ua>`).

### 2.5. Наявність та розміри
* Товари з `available="false"` або залишок $\le 0$ виключаються з фіду.
* Кожен товар повинен мати атрибут розміру (`<size>` або `<param name="Розмір">`). За відсутності встановлюється значення `Universal`.

## 3. АРХІТЕКТУРА ДЛЯ БЕЗКОШТОВНОГО CLOUDFLARE WORKER

* Готовий XML віддається за адресою:
  **`https://websklad.lozko1991.workers.dev/feed.xml`**
* **Принцип нульового CPU:** Cloudflare Worker **НЕ парсить і не модифікує** 45-мегабайтний XML у пам'яті (щоб не перевищити ліміти пам'яті 128 MB та CPU 10 ms безкоштовного тарифу).
* Worker працює виключно як потоковий proxy (stream) з GitHub Raw гілки `feeds-websklad`.
* **Кешування Edge:** кеш 4 години, причому кешуються тільки успішні відповіді `200-299`. Статуси `4xx` та `5xx` не кешуються.

---

## 4. АВТОМАТИЧНІ ТЕСТИ ТА ВАЛІДАЦІЯ ПЕРЕД ДЕПЛОЄМ

Файл `test-websklad.js` є обов'язковим шлюзом якості (Quality Gate):
1. **Unit-тести:** перевіряють точність формули націнки, коректність префіксу 1818, співвідношення oldprice > price та очищення тексту.
2. **E2E валідація файлу `websklad.xml`:**
   * Розмір $> 5$ МБ (захист від неповного завантаження).
   * Коректність тегів XML (баланс `<offer>` та `</offer>`).
   * Кількість товарів $> 1000$.
   * 0 товарів з ціною $< 150$ грн.
   * 0 товарів де `oldprice <= price`.
   * 0 товарів без обов'язкового префіксу `1818`.
3. **Поведінка CI/CD:** якщо бодай один тест падає, `test-websklad.js` завершується з кодом `1`. Команда `git push` скасовується, і в гілці `feeds-websklad` залишається попередній робочий прайс.
